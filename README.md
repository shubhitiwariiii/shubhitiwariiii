## Featured projects

### [ShelfSpace](https://github.com/shubhitiwariiii/shelfspace-v2) · [Live demo](https://shelfspace-v2.vercel.app)
Find libraries and study spaces on a map, with pricing, timings and amenities.

- OpenStreetMap data ingestion, decoupled from the app
- Idempotent upserts, so re-running ingestion doesn't create duplicates
- Row Level Security on Supabase
- Provider-agnostic database schema

**Stack:** Next.js, TypeScript, Supabase, Tailwind CSS, OpenStreetMap

### [First-Gen Guidance OS](https://github.com/shubhitiwariiii/first-gen-guidance) · [Live demo](https://first-gen-guidance.vercel.app)
Scholarship and career guidance for first-generation Indian students.

- AI scholarship matcher using the Gemini API
- Multi-step onboarding
- Student profile database with Row Level Security
- Deployed on Vercel

**Stack:** Next.js, TypeScript, Supabase, Gemini API, Tailwind CSS

### [Personalized Voice Assistant](https://github.com/shubhitiwariiii/personalized-voice-assistant)
A voice assistant that stores past conversations and uses them in later responses.

- Speech input and output
- Intent classification with Naive Bayes (scikit-learn)
- Persistent memory across sessions
- Runs on a local LLM through Ollama (LLaMA3)

**Stack:** Python, scikit-learn, Ollama

### [Daily Wage Tracker](https://github.com/shubhitiwariiii/daily-wage-tracker)
Wage and attendance management for contractors and workers.

- JWT authentication
- Worker and attendance management
- PDF report generation
- Deployed on Vercel (frontend), Render (backend) and MongoDB Atlas

**Stack:** React, Node.js, Express, MongoDB, JWT, Tailwind CSS
